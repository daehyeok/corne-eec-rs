# Firmware for a [Corne-eec](https://github.com/daehyeok/Corne_EEC)

Rust [Embassy](https://github.com/embassy-rs/embassy) and [Keyberon](https://github.com/TeXitoi/keyberon) based firmware for a split electrostatic capacitive keyboard.

![keyboard_img](img/right_keyboard.jpg)

# Hardware

Refer to [Corne-eec](https://github.com/daehyeok/Corne_EEC) for PCB and other hardware details.
